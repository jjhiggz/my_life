# higgzlife

AI-assisted life management system. Codex reads this repo, uses the higgzlife MCP server, and helps plan your days, track progress, and keep goals moving.

## Quick Start

1. **Ask Codex for today's plan**: "What should I do today?" or `/today`
2. **Log your day**: Fill out `logs/daily/YYYY-MM-DD.yaml`
3. **Update as things change**: Add tasks to `tasks/backlog.yaml`, update `goals.yaml`

## Structure

```
higgzlife/
├── profile.yaml          # Your context: location, constraints, preferences
├── goals.yaml            # Active goals and priorities
├── tasks/
│   ├── backlog.yaml      # One-off tasks and errands
│   ├── recurring.yaml    # Daily/weekly recurring items
│   └── skills.yaml       # Skills you're developing
├── plans/
│   ├── workouts/         # Workout templates
│   ├── diet/             # Nutrition guidance
│   └── daily/            # Daily plans generated by the agent
├── logs/
│   ├── daily/            # What actually happened each day
│   └── workouts/         # Aggregatable workout data (JSON)
├── garden/
│   ├── plants.yaml       # What you're growing
│   └── knowledge.yaml    # Gardening knowledge + quiz tracking
└── reviews/
    └── weekly/           # Weekly review notes
```

## How It Works

### The Feedback Loop
1. Codex reads your goals, backlog, and recent logs
2. Codex generates a daily plan (`plans/daily/YYYY-MM-DD.md`)
3. You do the things (or don't)
4. You log what happened (`logs/daily/YYYY-MM-DD.yaml`)
5. Codex learns and adjusts future plans

### Querying Your Data
The structured logs enable queries like:
- "How many workouts did I complete in March?"
- "What's my quiz score average this month?"
- "Show me weeks where I hit 80%+ task completion"

Use `jq` for JSON logs, or just ask Codex.

## Key Commands

Ask Codex things like:
- "What should I do today?"
- "Generate today's plan"
- "Quiz me on gardening"
- "How did I do this week?"
- "Add [task] to my backlog"
- "Log my workout: 30 min bike ride"
- "What should I plant this month?"

## Updating Goals

Edit `goals.yaml` when your priorities shift. The `priorities` list determines what Codex emphasizes in daily planning.

## Codex + MCP Setup

Codex project instructions live in `AGENTS.md`. The local MCP server lives in `tools/mcp-server` and shares the same SQLite database as the Tauri app.

Build the MCP server before first use:

```sh
cargo build --release --manifest-path tools/mcp-server/Cargo.toml
```

The checked-in `.codex/config.toml` points at `tools/mcp-server/target/release/higgzlife-mcp`, so rebuilding the release binary is enough after a fresh checkout.

## Mobile Access
